# L01 · 參考解答 · v0.1.0

將檔案解壓到同一個目錄。教材以 Python 3.13 為基準，僅使用標準函式庫。

- macOS／Linux：`python3 -X utf8 a.py`
- Windows PowerShell：`py -3.13 -X utf8 a.py`（若未安裝 `py`，改用實際的 Python 3.13 執行檔）

執行 Hello、`--name "林 小雨"` 及 `--mode hang --timeout 1.5`，保存各自輸出。

在同一個目錄執行 `python3 -X utf8 verify.py` 檢核，Windows 用 `py -3.13 -X utf8 verify.py`。起始碼有待完成項目，預期部分測試先失敗。
